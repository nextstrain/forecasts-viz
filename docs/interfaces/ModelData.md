# Interface: ModelData

Defined in: [utils/modelData.types.ts:10](https://github.com/nextstrain/forecasts-viz/blob/90e17ff143d6266cc094fc456c6d04e0ac6ca980/src/lib/utils/modelData.types.ts#L10)

The parsed model data structure.

Currently this is a `Map` representing the model data in its entirety,
generated ahead of time via the [useModelData](../functions/useModelData.md) hook. This may
change to a structure where the points, domains etc. are generated by
the visualisation component in the future. See `NOTES.md` for more.
